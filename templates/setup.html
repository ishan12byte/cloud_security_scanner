Cloud Security Scanner Setup Guide

Follow these steps to securely connect your AWS account and perform a read-only security assessment.

  • An active AWS Account
  • Permission to create IAM users
  • Python application running locally
  • Internet connection

Navigate to: 

AWS Console
    ↓
IAM
    ↓
Users
    ↓
Create User
    ↓
SecurityScannerUser
Never use the AWS Root Account for scanning. Always create a dedicated IAM user.

Attach AWS Managed Policy
ReadOnlyAccess

This policy allows the scanner to inspect AWS resources without creating, modifying, or deleting them. 

IAM User
    ↓
Security Credentials
    ↓
Create Access Key
    ↓
Local Code

Save the generated:

  • Access Key ID
  • Secret Access Key

Open the Connect AWS page.

Enter:

  • AWS Access Key ID
  • AWS Secret Access Key
  • AWS Region

Click Connect & Run Scan.
